# Mapa de contratos del backend

Fuente: Controllers y Features del repositorio .NET, revisados antes de crear el frontend. JSON usa camelCase; Guid es string, DateOnly usa YYYY-MM-DD y fechas UTC usan ISO 8601. Los enums se serializan numéricamente: no hay JsonStringEnumConverter en Program.cs. Todos los recursos son autenticados salvo auth y webhooks. TenantId viaja en query para lecturas y en body para comandos; no hay header X-Tenant-Id.

| Área           | Rutas y contratos principales                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Auth           | POST `/api/auth/login` `{email,password,tenantId?}`; POST `/register` `{tenantName,taxId,firstName,lastName,email,password}`; POST `/refresh` y `/logout` con `{refreshToken}`. Register devuelve 201, login/refresh 200, logout 204.                                                                                                                                                                                                                                                                                  |
| Respuesta auth | `{accessToken,expiresAtUtc,refreshToken,refreshTokenExpiresAtUtc,userId,email,tenantId,role}`. No incluye nombres de usuario/tenant ni lista de membresías.                                                                                                                                                                                                                                                                                                                                                            |
| Tenants        | POST `/api/tenants` (Owner) y POST `/api/tenant-members` (Owner); no hay GET de tenants/membresías.                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Billing        | GET `/api/billing/plans`; GET `/subscriptions/current?tenantId=` devuelve nullable `{id,subscriptionPlanId,planName,status,startsAtUtc,expiresAtUtc,autoRenew,providerSubscriptionId}`. Status: Active=1, PastDue=2, Canceled=3, Trialing=4. POST `/subscriptions` `{tenantId,subscriptionPlanId,annualBilling,autoRenew,paymentProvider}` devuelve `{subscriptionId,saaSInvoiceId,checkoutUrl,externalReference}`.                                                                                                    |
| Planes         | `{id,name,monthlyPrice,annualPrice,currency,maxUsers,maxWarehouses,maxInvoicesPerMonth,supportsAfip,isDefault}`. POST planes solo Owner. Webhooks son integración servidor/proveedor.                                                                                                                                                                                                                                                                                                                                  |
| Ventas         | POST `/api/sales/quotes` `{tenantId,customerId,expiresAtUtc,items:[{productId,quantity}]}`; POST `/invoices` `{tenantId,orderId,number,dueAtUtc}`; GET `/customers/{customerId}/account?tenantId=` devuelve entradas `{id,type,amount,description,occurredAtUtc}`. Roles Owner/Admin/Seller.                                                                                                                                                                                                                           |
| AFIP           | GET/PUT `/api/afip/fiscal-profile`. Configuración: `{tenantId,issuerTaxId,certificateContent,privateKeyContent,certificatePassphrase,certificateAlias,isPfxCertificate,environment,salesPoint,defaultConcept}`. GET devuelve perfil sin secretos. POST `/invoices/{invoiceId}/authorize` `{tenantId,invoiceId,voucherType,concept,exemptAmount,vatItems:[{id,baseAmount,amount}],serviceStartDate,serviceEndDate,paymentDueDate}` devuelve `{invoiceId,isApproved,cae,caeExpirationDate,barCode,errors}`. Owner/Admin. |
| Compras        | POST `/api/purchases/orders` `{tenantId,supplierId,warehouseId,items:[{productId,quantity,unitCost}]}`; POST `/orders/{id}/receive` `{tenantId,purchaseOrderId}`; POST `/invoices` `{tenantId,purchaseOrderId,number}`. Owner/Admin/Warehouse.                                                                                                                                                                                                                                                                         |
| Caja           | POST `/api/cash-registers/sessions` `{tenantId,warehouseId,openingBalance}`; POST `/sessions/{id}/movements` `{tenantId,cashRegisterSessionId,paymentMethod,amount,isIncome,description}`; POST `/sessions/{id}/close` `{tenantId,cashRegisterSessionId,closingBalance}`. Owner/Admin. No GET de sesiones en el controlador actual.                                                                                                                                                                                    |
| Analytics      | GET `/api/analytics/dashboard?tenantId=&date=` devuelve `{dailySales,monthlySales,estimatedGrossProfit,estimatedGrossMarginPercentage,processedOrders,averageTicket,totalReceivable,totalPayable}`. DailySales y MonthlySales son `{current,previous,variationPercentage}`. Owner/Admin.                                                                                                                                                                                                                               |
| Ranking        | GET `/api/analytics/products/top-selling?tenantId=&days=30&take=5` devuelve `[{productId,sku,name,quantitySold,revenue}]`; también export CSV, products/without-movement, inventory/low-stock e inventory/valuation.                                                                                                                                                                                                                                                                                                   |
| Depósitos      | GET `/api/warehouses?tenantId=` devuelve `[{id,code,name,address,isActive}]`. Owner/Admin/Warehouse.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Notificaciones | GET `/api/notifications?unreadOnly=false` devuelve `[{id,title,message,isRead,createdAtUtc,readAtUtc}]`; POST `/{id}/read` devuelve 204. Tenant y usuario se obtienen del JWT.                                                                                                                                                                                                                                                                                                                                         |

Los POST de operaciones suelen devolver 201 con Location e id en la URL, sin objeto en el cuerpo; recepción/cierre devuelven 204. No asumir DTO completo de creación.

Errores: ProblemDetails `{status,title,detail,instance,errors?}`; `errors` agrupa mensajes por propiedad. 400 validación/reglas de negocio, 401 autenticación, 403 autorización, 409 concurrencia, 429 límite de solicitudes. La suscripción también puede bloquear recursos; el cliente presenta el detalle recibido.

Tipos efectivamente utilizados por esta entrega: `src/types/api.ts`. Los comandos de módulos futuros quedan documentados; no se exponen operaciones incompletas.
